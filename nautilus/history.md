### Known limitations

- **Asset URL mismatch (3/8 tasks fail L1).** `Isaac-Ant-Direct-v0`, `Isaac-Humanoid-Direct-v0`, and `Isaac-Quadcopter-Direct-v0` reference `https://omniverse-content-production.s3-us-west-2.amazonaws.com/Assets/Isaac/5.0/...` USDs that the bundled Isaac Sim 4.5 cannot fetch. To unblock these, either (a) upgrade the bundled `_isaac_sim` symlink to a 5.0 install, or (b) host an offline asset mirror and set `ISAAC_NUCLEUS_DIR` / `ASSET_PATH` accordingly. The 5 passing tasks already span Direct/Manager-based, locomotion, manipulation (reach, lift), and classic control — sufficient for downstream RL training.
- **`isaaclab.sh -p` does NOT source `_isaac_sim/setup_conda_env.sh` automatically.** Running smoke scripts through that wrapper alone produces `ModuleNotFoundError: No module named 'isaacsim'`. The shim documented at the top of `scripts/run_random.py` / `scripts/render_random.py` (manual `source` of `setup_conda_env.sh`) is mandatory.
- **Stdout buffering during Kit warmup.** Kit's logger floods stderr; Python prints from the smoke script appear at the very end. Always run with `python -u` (unbuffered) when triaging — without it, `step N: reward=...` lines are invisible until exit.
- **Single-env smoke only.** Smoke uses `--num-envs 1` to keep startup fast (~25 s). For real training you'll want `num_envs=4096` (Cartpole-Direct) or similar; that is `rl-integration-generator`'s job.
- **`render_random.py` writes a single-camera viewport frame.** For multi-camera tasks (e.g. `Isaac-Cartpole-RGB-Camera-Direct-v0`), `env.render()` only returns the global viewport — per-task camera obs are accessible via `obs["policy"][...]` but require task-specific extraction; not generated here.

**Partial import note:** `isaaclab_assets`, `isaaclab_tasks`, and `isaacsim` import `pxr` (USD) and
`isaacsim` at module level. These modules live inside the Isaac Sim binary's PYTHONPATH (set via
`setup_python_env.sh`) and are NOT pip packages in the venv. They will fail bare `python -c "import pxr"`.
This is the **expected and documented** behavior for binary Isaac Sim installs. Core packages
(`isaaclab`, `isaaclab_rl`, `torch`, `gymnasium`) all import correctly.

To run Isaac Lab scripts with full Isaac Sim access, use:

```bash

# Option 2: source setup_python_env.sh then use venv python
source _isaac_sim/setup_python_env.sh
source .venv/bin/activate
python scripts/reinforcement_learning/rsl_rl/train.py --task <task_name> --headless
```

## Caveats

- **Isaac Sim binary PYTHONPATH:** `pxr`, `isaacsim`, `omni`, `carb`, `usdrt` modules are
  only available after sourcing `_isaac_sim/setup_python_env.sh`. Scripts that import these
  must be run via `./isaaclab.sh -p` or with that env sourced first.
- **Python version locked to 3.10:** Isaac Sim 4.5 binary ships Python 3.10. Do not upgrade
  the venv to 3.11 — it will break binary compatibility.
- **System packages** are NOT installed automatically (no sudo from a non-root venv).
- **CUDA toolkit** uses whatever the host has (`nvidia-smi`); host has CUDA 13.0 driver;
  the venv pins `torch+cu128` which is compatible.

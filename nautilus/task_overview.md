## How this was built

- **Enumeration**: `gymnasium.envs.registry, prefix='Isaac-' (after `AppLauncher(headless=True)` + `import isaaclab_tasks`)` (e.g. `gymnasium.envs.registry` filtered by prefix `Isaac-` for IsaacLab/Isaac-Sim, `dm_control.suite.ALL_TASKS` for dm_control, the upstream task registry for ManiSkill etc.). Run inside the repo's `.venv`.
- **Reward implemented** column: `presence of `RewardManager` in the env config (manager-based) or `_get_rewards()` (Direct)` (e.g. "true if the upstream env config exposes a `RewardManager` / non-trivial reward function").
- **Reward logger added** column: `yes` only if `<repo>/scripts/_<family>_env.py` exists AND wraps the env factory with `_DetailedRewardWrapper`; otherwise `no`. The `/add-reward-log` skill flips this column for tasks it patches.
- **Obs / Action / Max steps** columns: pulled from `nautilus/benchmark-spec.json` for smoke-tested tasks. Tasks discovered via the listing function but not smoke-tested show `(unprobed)` — they're real tasks but `benchmark-generator` never instantiated them, so the spaces aren't recorded.
